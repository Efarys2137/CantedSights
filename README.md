# Canted Sights (NVSE plugin, no ESP)

Requires xNVSE. Press the toggle key (default V) to switch canted/normal aim; hold aim (default RMB) to see it.
Tune everything in `NVSE/Plugins/CantedSights.ini` (roll sign, offsets, keys). V is VATS in vanilla: rebind one.

## Getting the DLL (no tools needed)
1. Make a free GitHub repo, upload this whole folder (keep `.github/workflows/build.yml`).
2. Actions tab -> "build" -> wait for green -> download artifact `CantedSights-MO2`.
3. Zip the artifact contents (the `NVSE` folder) and install in MO2 as a mod.
4. Play, then send me `Data/NVSE/Plugins/CantedSights.log` (or MO2 overwrite) and what you saw.
